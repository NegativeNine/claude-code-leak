# Research scope

- **Status:** bounded research candidate
- **Owner:** `agent-portfolio`

## Defensive purpose

This repository may be retained only to study source-map publication risk, provenance failures, software-distribution hygiene, and safe remediation. It is not a source release, product fork, development dependency, or vendor codebase.

## In scope

- static inventory of the pinned source map and extracted tree;
- identification of exact upstream package, version, digest, publication channel, and acquisition time;
- determination of authorization, licensing, redistribution, retention, and disclosure obligations;
- defensive guidance for preventing unintended source-map publication;
- content-addressed provenance and redaction evidence;
- archival or deletion planning.

## Out of scope

- asserting that the extracted tree is authentic, complete, current, or attributable to a named vendor without evidence;
- publishing or redistributing extracted code before license and authorization review;
- importing the extracted tree into R7, a product, a model corpus, an evaluation dataset, or another repository;
- executing unreviewed extracted code with credentials, network access, or production data;
- using the repository to bypass access controls or obtain unpublished source from a system not explicitly authorized for review.

## Authority disclaimer

This research owns no product, source-release, security finding, legal decision, credential, runtime, deployment, or `CurrentAuthority` state.
